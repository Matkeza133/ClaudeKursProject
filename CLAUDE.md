# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A personal learning workspace ("Claude Kurs"), scoped exclusively to **Python, HTML, CSS, and JSON**. The user is learning Python by comparing it to Pascal, which they already know. Files are standalone exercise scripts (`vezbaN.py` = "exercise N"), not a package or application — there is no build system, dependency manifest, or test suite.

HTML/CSS/JSON are in scope because upcoming work here includes building actual websites (static sites, HTML/CSS/JS front-ends, JSON as data/config). Stick to this stack — don't introduce other languages or frameworks unless the user asks.

`tempCodeRunnerFile.py` is auto-generated by the VS Code "Code Runner" extension when running a selection; it's disposable scratch output, not source to maintain.

## Running exercises

Run a script directly:
```
python vezba1.py
```
Scripts use `input()` for interactive prompts, so run them in a terminal rather than expecting output-only execution.

## Conventions in this codebase

Exercise scripts are heavily commented, with each Python concept introduced alongside its Pascal equivalent (e.g. `if/elif/else` vs `if...then...else`, 0-based list indexing vs Pascal's 1-based arrays, `def`/`return` vs `function...begin...end`). When adding or editing exercises, keep this Pascal-comparison comment style — it's the point of the exercise, not incidental documentation.
